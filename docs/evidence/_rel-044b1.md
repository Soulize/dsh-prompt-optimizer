## 0.4.4-beta.1 — 修掉两个已上报的缺陷（issue #9 / #8）

### #9 客户端「控件自愈」用同一 slot id 重挂，每 1.2 秒抛一次 pageerror
**根因**：slot 注册按 **id** 去重。自愈循环在控件仍未挂上时，用**同一个 `id: "prompt-optimizer"`** 再次
`ctx.slots.register(...)`，DSH 的 slot 系统直接抛
`list slot "conversation.input.left" already has an entry with id "prompt-optimizer"`；
改 `order` 绕不开——`order` 不是冲突键，冲突在 id（原注释"换优先级重挂"的推断是错的）。

**修复**：重挂前**先释放上一次的重挂**（保存 `ctx.slots.inject(...)` 返回的 disposer，下一次重挂前先调用；
定时器清理时也一并释放）。`shell.overlay` 的自愈结构相同，一并修掉（它此前因为"浮层没开就提前 return"而未暴露）。
顺带把重挂失败也记进 beacon（`remount-controls-failed` / `remount-overlay-failed`），失败不再无声。

### #8 本会话拦截次数显示为真值的两倍
**根因**：`record()` 只有一处 push，但**同一次发送会走两条路径**——Enter 键路径与随之触发的按钮点击路径
（`keydown-enter` 与 `click-send`），于是每次发送 push 两行，"本会话累计拦截次数"显示值恰好是真值的两倍（每次 +2）。

**修复**：把紧随其后的互补路径标记为 `coalesced`（遥测行照旧保留，便于排查），
并新增 `interceptCount()` 供显示使用（帮助面板标题、输入区徽标、控件内计数三处）。
自检与遥测里的 `store.intercepts.length` 保持原样（那里本就需要原始行数）。
