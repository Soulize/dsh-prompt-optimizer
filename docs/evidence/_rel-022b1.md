## v0.2.2-beta.1 · 界面中英双语（跟随 DSH 语言设置）

本版主功能是**国际化**：插件 UI 现在**中英双语**，语言**跟随 DSH「设置 → 通用 → 语言」**（`zh` / `en`），切换**即时生效、无需重启**；读不到语言服务时按中文兜底，**漏翻只显示中文、永不空白**。
同时：**产出语言跟随用户原话**（英文提问 → 通篇英文命令，不中英混排）。

### 覆盖范围（实测清单）
控件行（档位/权限/上下文/模型）· 上下文滑块（含 aria 与提示文案）· 档位标签（**英文 `Off / Low / High / Ultra`**）· **帮助面板 6 节 21 行** · **迷你窗**（栏目标题、状态行、常驻按钮、查证、原文折叠、回滚确认）· **提示条** · 模型弹层 · 通知与错误信息 · 悬浮球与署名行。

### 本轮顺手修掉的三个真缺陷
1. **后台标签页下探针/自检会永久挂住**：`frame()` 等两次 `requestAnimationFrame`，而后台标签页 rAF 不触发 —— 实测演示通道假死 90s 无回执。现改为 rAF 与 150ms 超时竞速。
2. **探针互斥标记卡死无自愈**：`__DPO_PROBE_RUNNING__` 一旦卡住，整个演示通道假死。现加 90s 陈旧自愈（`probe-stale-reset`）与 `probe-skip` 留痕。
3. **英文下仍有中文残留**：浮层状态行「上下文 N 回合」、查证行「N 步 / N行」、按钮「放行本条」等 40 处 + 43 条词典补齐；静态扫描（`evidence/i18n-missing.cjs`）现为渲染代码 **0 残留**。

### 安装
```bash
# 1) 下载本 Release 的 tgz，然后
dsh plugin --profile web add ./dsh-external-dsh-prompt-optimizer-0.2.2-beta.1.tgz

# 2) 若用 bundles 方式：在 ~/.dsh/profiles/web/package.json 的 dsh.profile.bundles 里加
#      "@dsh-external/dsh-prompt-optimizer"
#    或不改 bundles，直接在 ~/.dsh/profiles/web/cordis.patch.yml 里 insert 一条 entry（二选一，别都做）
```
安装后重启 `dsh web`；输入框左侧出现控件行即生效。文档：[README.md](https://github.com/WestFox-AwA/dsh-prompt-optimizer/blob/main/README.md)（中文）· [README.en.md](https://github.com/WestFox-AwA/dsh-prompt-optimizer/blob/main/README.en.md)（English）。

### 兼容性
**本版适用于 `dsh-0.1.6-alpha.1`**（`0.1.5-rc.1` 亦可运行）。升级 DSH 前请看 [DSH-COMPAT.md](https://github.com/WestFox-AwA/dsh-prompt-optimizer/blob/main/DSH-COMPAT.md)。

### 作者声明（照旧，不打折）
1. 本插件目的是优化提示词，省下写提示词的时间并让意思传得更准；本质是让 AI 多一步自我规划与约束。
2. 它在 **DeepSeek-V4.1-Flash** 这类能力强、但发挥受提示词影响严重的模型上作用明显。
3. 作者只测过部分 OneShot 类任务；README 里的实测数字都来自**特定测试题 + 特定评分卡**，**不代表你的任务一定提升**，请对实际效果持保守预期。
4. 完全开源，任何人任何形式使用与修改都欢迎；欢迎 Issue / PR / 各种测试反馈。
5. 界面已支持中英双语并跟随 DSH 语言设置（本版起）。

**English (short)**: this release makes the whole plugin UI **bilingual (Chinese / English)**, following DSH's *Settings → General → Language* and switching live; a missing translation falls back to Chinese, so nothing ever renders blank. The optimized output now follows the language of your own message. Three real defects were also fixed (probe self-check could hang forever in a background tab because `requestAnimationFrame` never fires; a stuck probe mutex had no self-healing; leftover Chinese strings in the English UI). Targets `dsh-0.1.6-alpha.1`. See [README.en.md](https://github.com/WestFox-AwA/dsh-prompt-optimizer/blob/main/README.en.md).
