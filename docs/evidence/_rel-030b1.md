## v0.3.0-beta.1 · 复杂任务能力包（细节逐项过关）

本版针对真实使用反馈：在较复杂项目里（一次性搭大场景、做精细可驾驶的 3D 坦克模型）会**在细节上出过分的问题** —— 法向量反了导致"该看见的面看不见、不该看见的面看得见"、各类操控 bug、交互方式不人性化。v0.3 让优化器在命中复杂域信号时，**把该域的失效模式逐条变成可检查的要求写进命令**。

### 新增：复杂任务能力包（高级/极端档；普通档不注入）
1. **现象量化**：先给怎么观测到问题（数值审计 + 视觉对照两条路），不许凭感觉。
2. **分域失效模式清单 → 逐条可检查要求**：
   - **3D/几何**：法线朝向一致且外观面朝外；坐标与单位/尺度约定；不得穿插悬空；碰撞体与网格一致；光照阴影不受朝向影响；判定标准（应从外部可见 / 不应从内部可见）；导入后检查固化（防复发）。
   - **交互/操控**：用户主流程；**输入映射表**（键鼠/手柄各一套）；每个操作有可见反馈；可发现；可恢复（暂停/取消/撤销/退出捕获）；可配置（灵敏度/反转/重绑）；**无障碍**（键鼠手柄并存/对比度/字号/色盲）。
   - **数据**：幂等、回滚并演练、边界数据、一致性校验、上线顺序与并发写入、回归验证方案。
   - **并发**：前端去重 + 后台幂等 + 失败/超时/重试语义 + 可观测 + 压测 + 不得引入死锁。
   - **性能**：先量化基线 → 按影响排序定位瓶颈 → 优化不得降画质（给等价替代）→ 目标值与达标线 → 每次改动后同时复核帧率与画质。
3. 全局验收场景 4. 不得降级清单 5. 影响面排序 + 范围边界与回退方式 + 不做项与停手条件 6. 判定标准与证据形式（没有证据不算完成）。
7. **细节缺陷自检**：交命令前逐条对照（法线/朝向/可见面、坐标单位、碰撞、输入映射与反馈、可恢复可配置、幂等回滚、并发去重与锁顺序、边界数据、性能预算与画质）。
8. **细节要求不得变成流程开销**：是否建 goal/todo/分阶段仍只由流程规则决定。

### 新增测试集（可复核，跑得快）
`evidence/lab-cx.cjs`：**8 道复杂题**（3D 场景 / 可驾驶坦克 / 法向量审计 / 交互人性化 / 跨模块重构 / 数据迁移 / 竞态 / 性能预算），
每题 **6 条要点 × 4 档**（0 缺失 / 1 模糊提及 / 2 可判定要求 / 3 可判定 + 验证或边界），**每题满分 18、全表满分 144**，达标线 60% / 83% / 100%；
判分**确定性执行**（概念级同义扩展，不额外调用 LLM）。

### 实测（8 题 × 2 次采样 = 48 格，并发 4，共 230 秒）
| 条件 | 得分 | 满分 144 换算 | 达标 |
|---|---|---|---|
| 无优化（对照） | 6/288 | 3 | 未达标 |
| 发布版 0.2.2-beta.1（极端档） | 201/288 = 69.8% | 101 | 及格线 |
| **v0.3.0-beta.1（极端档）** | **265/288 = 92.0%** | **132** | **目标线** |

- 逐题配对：**胜 7 / 负 0 / 平 1**（C1 场景 +11.5、C2 坦克 +4.5、C3 法向量 +3.5、C4 交互 +4.0、C5 重构 +4.5、C6 数据 0、C7 竞态 +2.5、C8 性能 +1.5）。
- 重复采样噪声：同格平均极差 **0.75 分/18**（最大 5）。
- **简单任务回归**：4 道原题复杂包泄漏 **0/4**、命令长度 **1.11×**、流程索取不比发布版重 → PASS。
- 提示词约束闸门：**34 项断言全 PASS**（含"普通档不得出现能力包"反向断言）。

### 诚实边界
- 测的是**命令侧**（优化器要求工作 AI 做什么），不是最终产物质量；答案侧对复杂题全量评分成本高，本轮未做。
- 单格 n=2，个别格仍可能差 1~2 分；C6（数据迁移）发布版已满分，该题不再有区分度。
- 走过的两条弯路已记入 `PROMPT-OPTIMIZATION.md` 第九节（判分器措辞过窄 → 概念级同义扩展；一度加"规模闸门"导致复杂题掉到 81.9% → 改为"细节按域全覆盖、流程开销才按规模裁剪"）。

### 安装

```bash
dsh plugin --profile web add ./dsh-external-dsh-prompt-optimizer-0.3.0-beta.1.tgz
# 或不改 bundles，直接在 ~/.dsh/profiles/web/cordis.patch.yml 里 insert 一条 entry（二选一）
```

**English (short)**: v0.3 adds a *complexity capability pack* for the Advanced/Ultra tiers: when a task hits a complex domain (3D/geometry, interaction, data, concurrency, performance), the command must enumerate that domain's **failure modes as checkable requirements** — normal orientation / visible faces, axes and units, collision matching the mesh, input mapping with feedback, recoverability, idempotency and rollback, de-duplication and lock ordering, boundary data, performance budget vs. visual quality — plus quantified symptoms, a global acceptance scenario, a no-downgrade list, scope boundary, and required evidence. Measured on a new 8-task suite (6 criteria x 4 levels, max 144, deterministic grading): **no-optimization 2.1% / shipped 69.8% / this build 92.0%**, paired 7W-0L-1T, suite runs in 230 s, with zero leakage on simple tasks.
