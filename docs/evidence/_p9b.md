### 9.1 v0.3.0-beta.2：扩容、答案侧与一个能力缺口（2026/09/15）

**测试集扩容**：8 题 → **10 题**、满分 144 → **180**。新增 C9 载具物理细节（斜坡打滑/抖动/陷地/穿模、物理帧与渲染同步、手感可控性）与
C10 存档与配置持久化（原子写入、版本迁移、损坏恢复、并发写取舍、可观测）。

**能力缺口修复（本轮唯一提示词改动）**：逐题复查发现能力包的**分域清单漏了"重构/多模块"**，导致 C5 跨模块重构一度比发布版低 2 分。
补上该域（调用面盘点 → 对外兼容或薄适配 → 分阶段且每阶段可验证 → 回归验证方案 → 可回退/开关/灰度 → 不趁机扩大范围）后，C5 两次采样均 **18/18**。
提示词规模：高级/极端 4582 / 4580 字符（普通档仍 1405，且闸门有"普通档不得出现能力包"的反向断言）。

**命令侧复测（10 题 × 2 次采样 = 60 格，并发 4，289 秒）**：无优化 8/360（2.2%）· 发布版 273/360 = **75.8%** · v0.3 325/360 = **90.3%**（换算满分 180 → 163，目标线）。

**答案侧首轮（relay → solve → judge，5 题 × 3 条件 = 15 格）**：无优化 51.1% · v0.3 47.8% · 发布版 23.3%。
- 有效信号：数据/持久化题（可纯文本回答）v0.3 **17/18 对 发布版 0/18**。
- **测量局限（必须一起读）**：测量台里的执行 AI **没有文件系统/引擎工具**，3D 类题（C1/C2/C9）只能给方案不能落地，全体贴地板；
  而"无优化"因为输出宽泛反而拿到虚高的覆盖率分。因此答案侧**只作辅证**，主指标是命令侧。
- 口径修正：首轮答案侧曾出现 10/30 格评分 JSON 解析失败、6 格空产出；已加"空产出重试 + 评分 JSON 容错解析 + 解析失败修复重试"，
  复跑 15/15 全部评分成功。

**噪声与配对（诚实标注）**：同格重复采样平均极差 1.07 分/18、最大 7；逐题配对计数随批次波动（本轮 6 胜 2 负 2 平，上一轮 8 胜 1 负 1 平）。
C3/C9 的 −1 分在噪声内 —— 可复述的稳定结论是"**总分 90% 对 76%**"，不是"每题都赢"。

**复现**：`node evidence/lab-cx.cjs`（10 题/180 分）→ `cxlab`（宿主内，mode=command 或 full）→ `cx-grade.cjs` → `cx-stats.cjs`；
答案侧再跑 `cx-answer-grade.cjs`；简单回归 `lab-simple.cjs` + `cx-simple-check.cjs`。
