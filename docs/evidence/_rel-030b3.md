## v0.3.0-beta.3 · 复杂任务能力包（可自动化验收 + 复杂度闸门）

### 本版新增：可自动化验收能力
用户说"我要能自动化验收 / 能自测 / 我要跑检查"时，命令必须把**验收接口原样带进命令**（接口名、返回值、判据），并要求自检**能在无浏览器/无引擎的纯计算环境独立跑通**（不依赖 DOM 事件、不依赖闭包外部变量、不递归爆栈）、**接口挂到全局**。
触发原因是实测出来的：产物级验证台发现 2/4 份产物连 `window.__selftest` 都没暴露，无法自动验收。

### 复杂度闸门加固（取舍，如实记录）
- 未命中复杂信号：命令里**不得出现**（现象量化 / 失效模式 / 全局验收场景 / 不得降级清单 / 本轮不做项 / 停手条件 / 证据形式 / 可自动化验收），长度 ≤ 原话 1.5 倍或 800 字。
- 加固前：复杂题 **93.9%**，但简单任务回归**不合格**（复杂包泄漏 1/4、长度 1.37×）。
- 加固后：复杂题 **88.9%**（仍高于 83% 目标线），简单任务回归 **PASS**（泄漏 0/4、长度 **0.95×**，比发布版更短）。
- 用约 5 分复杂题换回"简单任务不被撑长/不越权"，是有意选择，不是纯提升。

### 命令侧实测（10 题 × 2 次采样 = 60 格，并发 4，265 秒，满分 180）
| 条件 | 得分 | 换算满分 180 | 达标 |
|---|---|---|---|
| 无优化（对照） | 8/360 = 2.2% | 4 | 未达标 |
| 发布版 0.2.2-beta.1（极端档） | 266/360 = 73.9% | 133 | 及格线 |
| **v0.3.0-beta.3（极端档）** | **320/360 = 88.9%** | **160** | **目标线** |

- 配对：**胜 7 / 负 2 / 平 1**；同格重复采样平均极差 **0.93 分/18**（最大 5）；差距最大的是 C1「3D 场景一次性搭建」（+11.5）。
- 评分卡：10 道复杂题 × 6 条要点 × **0/1/2/3 四档** = 每题 18、**全表 180**；判分确定性执行（概念级同义扩展，0 次额外 LLM 调用）。
- 简单任务回归：泄漏 0/4、长度 0.95× → PASS。约束闸门 34 项断言全 PASS。

### 产物级验证台（单文件 HTML，独立审计，不依赖浏览器）
- **验证器自证**：`gold.html`（按"从外看逆时针"构造）**15/15 PASS**；`bad.html`（绕序整体反转）**FAIL 且独立审计 inwardFaces=12**。
- **真实产物**（H1 法线盒体 / H3 审计并修复反向面，两条件）：**通过 3/6**；SHIP H1、SHIP H3、V3 H1 均 PASS 且 `inwardFaces=0`；其余 3 份 FAIL 的原因都是**产物没把接口挂到全局**（验证器取不到几何）。
- 命令侧 4/4 都要求了该接口 ⇒ **瓶颈在执行 AI 的接口一致性，不在优化器**。
- 期间抓到的真实缺陷：V3 某次 H3 产物 `buildGeometry` 调用即**爆栈**；另一份 60 面中 **22 面朝内**（比例 0.63）——正是"该看见的面看不见"。

### 安装与兼容
```bash
dsh plugin --profile web add ./dsh-external-dsh-prompt-optimizer-0.3.0-beta.3.tgz
```
**本版适用于 `dsh-0.1.6-alpha.1`**（`0.1.5-rc.1` 亦可）。文档：[README.md](https://github.com/WestFox-AwA/dsh-prompt-optimizer/blob/main/README.md) · [README.en.md](https://github.com/WestFox-AwA/dsh-prompt-optimizer/blob/main/README.en.md) · 实测细节见 `PROMPT-OPTIMIZATION.md` 第 9 节与 `ACCEPTANCE.md` 第 8/9 节。

**English (short)**: adds an "automatable acceptance" requirement (when the user asks to be able to verify/self-test, the command must carry the exact acceptance interface and require a self-check that runs standalone in a pure-compute environment with the interface exposed globally), and hardens the complexity gate so simple tasks are not bloated (this trade cost ~5 points on the complex suite: 93.9% → 88.9%, both above the 83% target line, while the simple-task regression went from failing to passing at 0.95x length). Also ships a browser-free artifact-level harness that independently audits face-normal orientation of generated single-file HTML artifacts (self-validated: good fixture 15/15, inverted fixture fails with 12 inward faces).
