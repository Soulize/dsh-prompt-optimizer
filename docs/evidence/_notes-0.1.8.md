**上下文模式：回合（0~10）/ 全文（与工作 AI 看到的上下文一致）**
- 回合量程从 0~100 收到 **0~10**：100 回合足以把优化模型的上下文撑爆；宿主夹紧同步改为 10（写 999 → 10、写 12 → 10、写 -5 → 0）。
- 滑块右侧**贴着**一枚「回合 / 全文」转化按钮（同一胶囊内、竖线分隔、点一下换一态）：
  - **回合**：滑块 0~10 档，只带用户原话（工作 AI 回复只留长度与工具次数，防污染）。
  - **全文**：滑块两档 **关 / 开**；开启后把工作 AI 当前看到的完整上下文（双方全文）交给优化模型，总预算 **60000 字**，超限**整回合省略**、绝不截断单条约束。
- 实测（活会话 `session-ae0b2c09…`）：回合态 `turns=10 → 10 回合 / 10356 字 / 省略 0`；全文态 → `25 回合 / 57591 字 / 整回合省略 93`；全文态关闭 → 不带历史（`history:null`）。
- 模式与开关随配置落盘（`historyMode` / `fullOn`），非法值自动回落 `turns`（写 `bogus` 读回 `turns`）。

**UI 扁平化极简（对齐 DSH 观感）+ 底栏压缩**
- 去掉渐变、内阴影、玻璃拟态与"实体感"高光：胶囊 / 滑块 / 模型钮 / 帮助钮统一 **26px 高**、**7px 圆角**、单层平色底 + 1px 描边；轨道 3px、圆钮 12px 平色。
- 底栏行高 26px 且贴底：实测宿主容器 28px、控件行 26px、底边对齐 → **不再把输入框挤上去**。
- 圆钮两端各内缩 6px（新增 `.dpo-range-inner` 行程道）：0% / 100% 时圆钮**不再越出轨道**（修复前实测越界 8px）。
- 交互与无障碍不变：拖动 / 点击 / ←→（Shift ±10）/ PageUp-Down / Home-End；`role=slider` 落在轨道上（胶囊去掉 slider 语义，避免按钮嵌进 slider），回合态 aria `max=10`、全文态 `max=1` 且文案「全文 关 / 开」。
