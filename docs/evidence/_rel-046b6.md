# v0.4.6-beta.6 — 根治「假事实」：身份层 + 证据层 + 契约层

作者：啃轮胎的西狐 · 2026/09/18

## 病灶（真实项目实测，8 条运行记录）

| 现象 | 证据 |
|---|---|
| **工具根目录读错** | `resolveSessionCwd()` 取"会话列表里**第一个**有 cwd 的"（`lib/index.js:1239`），与本次运行无关 → 读到 `C:\Users\WestFox\.dsh`；46 次工具调用里 **34 次 `glob`**、`read` 只有 2 次 |
| **假事实被当成"已核实"** | 产出写"工作目录下不存在任何工程文件…只有 `attachments/v1/objects/**` 二进制对象"，并标注"**已核实，不要再去找别的资料**"→ 下游不再看真实项目 |
| **歧义升级成硬约束** | 同一句原话三次跑出**互相冲突**的边界：一次"唯一允许的外部资源是 CDN three.js"，一次"不得出现 `https://`"＝要求从零手写 WebGL 渲染器（用户从没要求）→ **渲染问题与大量 bug 的直接来源** |
| **上下文没生效** | 8 条里 6 条 `observer={chars:0}`（同一个"猜会话"病根） |

## 根治（四层，都是结构改动）

1. **身份层**：`resolveRunContext()` 成为**唯一入口**——按本次运行上报的 sessionId 解析会话 / cwd / preset。**解析不到就不猜**：不派工具、不注入观察者、形态回落 chat（退化成 0.4.3 的"纯需求重述"），**绝不产出假事实**。判定写进 `/runs` 的 `context` / `toolRoot`。
2. **证据层**：`renderEvidenceLedger()` 把"本次**实际读到**了什么"作为**结构输入**交给模型（与观察者块同构）。规则由机制背书：只能引用账本里出现过的路径 / 符号；**只列过目录不等于知道内容**；一次文件内容都没读到就不许写"事实 / 现状"段。
3. **契约层**（`V6_CORE`）：新增【事实必须有出处】【只写下游无法自知的】；【歧义】扩写为"**保守不得升级成新的硬约束**"（用户没提 ≠ 禁止）。
4. **形态表述精化**：`sequence=unordered` 从"不写先后顺序"改为"**真实依赖写进条目本身**"（去掉往返节奏、保留依赖）。
