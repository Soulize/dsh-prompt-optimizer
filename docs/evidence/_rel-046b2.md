# v0.4.6-beta.2 — 只读权限默认开 · 文案与位置 · 产出物收件人（治根）

作者：啃轮胎的西狐 · 2026/09/18

## 1. 只读权限默认开（原话："让读取工具默认开启"）

改成**三态**：状态文件里**缺失该键 = 开**；只有**显式 `false`** 才算关（已保存的显式值不被改写）；读取异常也按开处理。
浏览器侧同步三态（`null` = 未读到就**不上报该字段**），否则"未设置（默认开）"会被 UI 首次落盘误写成显式 `false`。

实测：删掉 `readTools` 键后 `GET /state` → `true`；不传任何参数跑极端档 = **6 次真实工具调用**（`glob`/`grep`）；显式 `false` = 0 次调用、产出 4000 字。

## 2. 文案与位置（原话："只读查证（让优化 AI 真的读项目）改成「只读权限：」，按钮放在右边"）

标签改为 **`只读权限：`**（en：`Read-only access:`），开关控件移到标签**同一行的右侧**，说明保留在下一行。

真实 DOM 实测（`popover-demo` 探针）：`toolsLabel="只读权限："`、`toolsOn="true"`、`sameLine=true / dy=0 / btnRightOfLabel=true / overflowRight=-25`（不出界、标签未截断）。

## 3. 产出物收件人（治根）

原话指出极端档产物第一句是**对老板说的**——"把下面这段整条发给工作 AI（原话里的两件事：…）"——直接转发容易误导会话 AI。
**优化 AI 是领导，产出物只能对员工（会话 AI）说话。**

病根：契约只规定了"内容要像一条能发出去的命令"，**从未规定产出物的收件人**，模型于是把产出物当成"回给老板的信"。两层根治：

- **契约层** `OUTPUT_ADDRESSEE_CONTRACT`：收件人写进 system，`buildSystem` **统一追加**（全策略、全档位生效，放最后 = 模型看到的最后一条产出规则）；
- **闸门层** `enforceAddressee`：宿主在**唯一产出出口**强制剥离首尾转交语与包装。只扫首尾（正文里的"复制到 / 告诉我"不误伤）；剥完不足 20 字**整段回退原文**；处理结果写进 `run.addressee` 供 `/runs` 复核；`done.text` 成为**定稿**，流式 delta 只作预览。

实测：用出问题的那句原话复现 → 产出 `addressee = {triggered:false, action:"no-hit"}`，**转交语根本没生成**；闸门判官自检 **13/13**（坏标全拦、金标一字未动、含 4 条误伤压力用例）。

## 降级（硬约束）

`forceToolError` 让只读工具链失败 → `toolLoopError` 记录在案、**回落无工具路径**、产出 **3816 字非空**；闸门任何异常原样放行。**任何失败路径都不给空结果。**

一处判断：降级/失败声明落在**运行记录**（`toolLoopError`、`/runs`），**不写进产出物**——产出物是给会话 AI 的指令件，在里面写"已降级"就又变成对老板说话。

## 验证脚本（新增）

- `verify-addressee.cjs`：闸门判官自检（坏标必拦 / 金标一字不改 / 绝不返回空）；
- `verify-046b2.cjs`：默认开 / 显式关 / 降级非空 / 收件人 四项一次跑完（输出 `verify-046b2.json`）；
- `probe-tools-row.cjs`：走宿主 `popover-demo` 探针读**真实 DOM** 的只读权限行。
