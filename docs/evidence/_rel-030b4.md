## v0.3.0-beta.4 · 产物级验证扩到 H1/H2/H3 + 接口独立性优化

### 新增：一键产物级检查
`node evidence/artifact-check.cjs` —— 扫描 `evidence/artifacts/*.html`，按题型调用验证器（H1/H3 走"法线-修复"口径、H2 走"操控"口径），
汇总"条件 × 题"通过率与独立审计 `inwardFaces`，落盘 `evidence/artifact-check.json`（可复核）。

### 产物级实测（H1 法线盒体 / H2 操控 / H3 审计并修复反向面，两条件各 2 次）
| 条件 | 通过 | 说明 |
|---|---|---|
| 发布版 0.2.2-beta.1 | **4/5 = 80%** | H1 1/1、H2 2/2（独立审计 inwardFaces 全 0）、H3 1/2 |
| **v0.3.0-beta.4** | **4/5 = 80%** | H1 1/1、H2 2/2（inwardFaces 全 0）、H3 1/2 |

### 数据驱动的定向优化（本轮提示词改动）
产物级数据显示 v0.3 在 H3 上 **0/2**：产物把几何构造藏进闭包、依赖外部辅助函数，第三方只取 `buildGeometry()` 取不到。
→ 把"可自动化验收"要求写死为：**几何构造与自检写在同一个可独立取用的函数里（或把依赖一并导出）**。
→ 重跑后 **v0.3 H3 追平发布版（1/2），产物级总通过率 60% → 80%**。

### 诚实边界
- 产物级样本太小（每题 n≤2）：两条件在产物级**打平**，不能据此说产物质量有差异。
- H3 剩余失败仍是"接口未暴露到全局"，属**执行 AI 的接口一致性**；命令侧 4/4 都已要求该接口。
- 生成一份产物约 2～13 分钟，采样数受时间限制。
- 命令侧（同批，未变）：无优化 2.2% · 发布版 73.9%（133/180）· v0.3 **88.9%（160/180，目标线）**；配对胜 7 / 负 2 / 平 1；噪声平均极差 0.93 分/18。

### 安装与兼容
```bash
dsh plugin --profile web add ./dsh-external-dsh-prompt-optimizer-0.3.0-beta.4.tgz
```
**本版适用于 `dsh-0.1.6-alpha.1`**（`0.1.5-rc.1` 亦可）。细节见 `PROMPT-OPTIMIZATION.md` 第 9 节、`ACCEPTANCE.md` 第 8/9 节、`evidence/artifact-check.json`。

**English (short)**: adds a one-command artifact-level check (`artifact-check.cjs`) covering three task types (normals box / controls / audit-and-fix inverted faces) and an executor-visible interface refinement driven by that data: the geometry builder and self-check must live in one independently callable function (or export their dependencies), because the working AI's artifacts kept hiding the builder in a closure. Result: v0.3's H3 artifact pass rate went 0/2 → 1/2 and the overall artifact pass rate 60% → 80% (shipped build: 80%). Sample sizes are small (n≤2 per task) and the two conditions tie at the artifact level — reported as such, not as an improvement in artifact quality.
