# Bash 可靠性与耗时改进计划（本地实施）

状态：用户已授权在测试顾问期间实施。改动仅在本地开发目录，不重载、不重启打断正在测试的宿主；不提交、不push或发布。

## 已实施与验证边界
- 执行入口传递融合取消与截止信号，准备阶段计入总耗时；独立调用目录、输出文件UUID、退出标记始终最后。
- stdout/stderr成功和失败都保留，分别截尾并提供完整文件指针；stderr截断不判命令失败。
- governor所有出口释放句柄；正常root退出检查Job残留，native同时关闭process与job。fallback异步有界taskkill，不能证明树清空时明确not-evaluated。
- 输出使用有界readSync字节窗口和UTF-8边界，返回真实totalBytes、窗口偏移及编码诊断。
- 运行时定位改可取消异步探测，成功缓存5分钟，候选环境/PATH/文件指纹改变失效；失败不缓存；启动失败清缓存。fileURLToPath修中文/空格路径，PATH去除大小写重复。
- 调用记录按session和UUID隔离、finally清理，仅确认死owner记录提示。低输出不是纯损失，链结构只说风险，快成功不打扰。
- MSYS原生参数转换和BASH_ENV继承不擅改；cwd映射不是完整命令沙箱。未承诺真实native/脱离父链子孙绝对清空，也未做bash/pwsh配对性能结论。

## 最终验证
全量67份测试通过；新增入口/输出/缓存/诊断/治理测试，治理19项、保守诊断15项，真实仅短Node输出与ENOENT烟测。独立复核提出“探测取消后等待close可能无界”，已增加2秒收尾观察上限；到点不回落候选，明确未确认退出，相关确定性断言通过。复核输出因非法引用未被校验器采纳，不宣称顾问整体验收通过。最终diff-check干净。真实native与MSYS脱离父链场景待用户手测。

## 证据与边界
近期12个HTML工作区会话364次已结算bash调用，中位2.171秒；52次超过60秒，占累计调用墙钟86%；27次异常/非零/超时不是工具正确率。最近3会话13次无超过60秒。pwsh任务样本不同，不得据此断言bash普遍更慢。空字节结果存在，但没有直接证据证明由并发覆盖导致。

## 优先整改
1. 执行入口将exec.signal传入runGoverned；取消、超时都等待受管进程收尾，不把ABORTED当已经硬杀的证据。
2. 每次调用独立输出目录/文件，避免tool-pid+重置计数器导致out-1/err-1复用；保留spill指针的生命周期。
3. 失败返回保留stdout/stderr及正确的截断/完整输出路径；stderr截断不得把exit=0判成命令失败。
4. 提示内容放在exit marker前，或者用结构化退出状态；修复失败与低输出成功的状态药丸消失。
5. Win32 Job/process句柄完整释放；确认正常结束仍存活子进程的治理语义；fallback同步taskkill及grace等待分别计时。
6. 每次bash --version探测改为可失效缓存；计时覆盖resolve/probe/spawn/execute/output/cleanup全阶段，记录真实开销。
7. 大日志按文件窗口读取，不先同步读完整文件再截尾；16000字符二次截断始终保留完整路径，说明前/尾与实际一致。

## 诊断机制纠偏
- inflight按调用/会话隔离，不用全局单文件及年龄直接断言“纯损失”；catch正常交回错误也须收尾。
- chainFinding只报风险，不把;|/||等同必然吞错；考虑pipefail/set-e/引号转义。
- 字符数不冒充字节数，不能把少stdout等同没有成果（stderr/落盘成果均可能有效）。
- fallback spawn error携带真实原因，避免归类成普通exit；编码诊断和输出窗口边界如实显示。

## 兼容性与测试
中文/空格安装路径用fileURLToPath；确认MSYS原生程序参数转换、PATH大小写及BASH_ENV行为。工具cwd限制不等同完整命令沙箱。
针对执行→输出→客户端的集成断言，以及并发、旧spill稳定性、取消信号、句柄收尾、stderr溢写、spawn错误新增确定性测试；现有bash测试多是纯字符串或注册守卫，不代表执行链健康。
后续只用相同命令/目录/运行时的配对测量比较bash与pwsh，避免把重型浏览器任务与轻量命令混比。
